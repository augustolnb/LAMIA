O passo a passo ensina a configurar uma automação local de WhatsApp integrando n8n e a API WAHA (WhatsApp HTTP API), utilizando o Docker Desktop sem necessidade de pagar servidores ou serviços de hospedagem (VPS).1.Instalar e Configurar o Docker Desktop:Base para rodar o n8n e a API do WhatsApp no computador.Acesse o site oficial do Docker e faça o download do Docker Desktop compatível com o seu sistema operacional (Windows, Mac ou Linux).Instale o programa e abra o Docker Desktop após a conclusão.2.Instalar e Configurar o Container do n8n:Plataforma de automação de fluxos de trabalho.No campo de busca superior do Docker Desktop, pesquise por n8n.Localize a imagem oficial e clique em Pull para realizar o download.Após o término do download, clique em Run e abra as Optional settings:Container name: Digite n8n (ou outro nome sem espaços, ex: n8n-aula).Ports: Defina a porta de acesso como 5678 (mapeamento 5678:5678).Volumes:Container path: /home/node/.n8nHost path: Clique nos três pontos e selecione uma pasta no seu computador para salvar os dados (ex: C:\n8n).Environment Variables:GENERIC_TIMEZONE = America/Sao_Paulo (garante o fuso horário correto).Clique em Run. Aguarde o container inicializar e clique no link disponibilizado (ex: http://localhost:5678) para abrir o n8n no seu navegador.Crie sua conta de usuário e conclua o cadastro inicial.3.Instalar o Nó Comunitário da WAHA no n8n:Permite ao n8n comunicar com a API do WhatsApp.No painel do n8n, acesse Settings (ícone de engrenagem) > Community Nodes.Clique em Install a community node.Cole o nome do pacote da integração do WAHA (@devlikeapro/n8n-nodes-waha), marque a caixa de concordância e confirme a instalação.4.Instalar e Configurar o Container da WAHA (WhatsApp API):Serviço gratuito para conexão com o WhatsApp Web.Volte ao Docker Desktop e pesquise por waha (imagem oficial devlikeapro/waha).Clique em Pull e aguarde o download.Clique em Run e configure as Optional settings:Container name: Digite waha.Ports: Defina a porta 3000 (3000:3000).Volumes:Container path: /tempHost path: Escolha uma pasta no seu computador (ex: C:\waha).Environment Variables:WHATSAPP_DEFAULT_ENGINE = WEBJSWHATSAPP_HOOK_EVENTS = messageWHATSAPP_HOOK_URL = Cole a URL de produção do Webhook do n8n (extraída do n8n), alterando localhost para host.docker.internal (ex: [http://host.docker.internal:5678/webhook/](http://host.docker.internal:5678/webhook/)...).Clique em Run para rodar o container.5.Conectar o Seu WhatsApp ao Dashboard da WAHA:Emparelhamento do número via QR Code.Acesse o painel da WAHA pelo navegador em http://localhost:3000 e clique em Dashboard.Na sessão padrão (default), clique para iniciar (Start/Login).Abra o WhatsApp no seu celular, vá em Menu/Configurações > Dispositivos conectados e escaneie o QR Code exibido na tela.6.Criar o Workflow de Automação no n8n (Bot Respondedor):Construção do fluxo de envio e recebimento de mensagens.No n8n, crie um novo workflow (ex: Ping-Pong).Adicione o nó inicial WAHA Trigger:Copie a Test Webhook URL gerada pelo nó.Na WAHA (http://localhost:3000), edite a sessão default, adicione essa URL nos Webhooks e substitua localhost por host.docker.internal.Clique em Test step no n8n e envie uma mensagem para si mesmo no WhatsApp para capturar o evento de teste.Adicione o nó Edit Fields (Set) para mapear os dados da mensagem recebida:session ➔ payload.sessionquem_mandou ➔ payload.frommensagem ➔ payload.bodyid_mensagem ➔ payload.idAdicione o nó WAHA (Send Seen) para marcar a mensagem como lida:Crie a credencial apontando para [http://host.docker.internal:3000](http://host.docker.internal:3000).Preencha os campos session, chatId (quem_mandou) e messageId (id_mensagem). Remova o campo participant.Adicione o nó WAHA (Send Text) para responder a mensagem:Preencha session, chatId (quem_mandou) e no campo de texto digite o retorno desejado (ex: Você digitou: {{ $json.mensagem }}).Ative o workflow no n8n para rodar em produção.Dicas de Operação e ReinicializaçãoExecução Local: Todo o sistema roda na sua própria máquina. Se o computador for desligado, as automações param de responder.Reiniciando o sistema: Ao ligar o computador novamente, abra o Docker Desktop, inicie os contêineres do n8n e do waha, acesse http://localhost:3000 e certifique-se de dar Play/Start na sessão do WhatsApp na WAHA.
